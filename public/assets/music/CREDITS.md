# Bloodline Legacy — Celtic score

Four original compositions and arrangements, authored for Bloodline Legacy:
風待ちの広場 / 遥かな丘を越えて / 受け継がれる灯 / 血脈の旗のもとに.
No existing song, commercial recording or demo MIDI was transcribed or incorporated.
The user may use, edit and distribute these compositions/recordings with the game.
