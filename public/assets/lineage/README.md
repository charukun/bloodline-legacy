# Lineage presentation assets

These assets accompany the user-approved interactive lineage prototype, version 8
(2026-09-09). They are UI illustrations, not replacement character models.

- `race-illustrations.png`: original image generated for this project. Four
  illustrative bloodline motifs; not portraits of actual saved characters.
- `memory-0..3.mp4`: original 8-second, 768×768, 24fps silent H.264 loops composed
  from the above art and procedural botanical layers. One decoder is active;
  leaving lineage removes its source and aborts view-owned listeners.
- `poster-0..3.jpg`: still fallbacks from those same loops. No reference video or
  reference screenshot pixels are used.
- `ledger-serif.ttf`: subset of Noto Serif JP; copyright Adobe 2017–2024.
  SIL Open Font License 1.1 in `OFL.txt`; the license is embedded in standalone
  HTML as well. Characters outside the subset use the existing system serif.
- Parchment and cloth textures reuse the existing game assets in the parent
  directory. All text, layout and controls are native HTML/CSS, not image maps.
