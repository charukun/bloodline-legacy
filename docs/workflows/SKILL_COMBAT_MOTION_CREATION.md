# Skill / Combat Motion Creation

適用範囲・証拠の形式は [Workflow入口](README.md)。技・戦闘モーションと同期するVFX / SFXの制作・改修に使用する。

## 標準工程

コンセプト → 序破急・移動軌道・タイミング設計 → Motion → VFX / SFX → 実戦Simulation / Review Lab確認 → 修正

| 工程 | 中間成果物 | 次工程へ進む品質ゲート |
| --- | --- | --- |
| コンセプト | 技の役割、武器・対象・見せ場、既存技との差、必要なポーズ／動画Reference | 確定仕様の技構成・発動条件と整合し、攻撃の方向・強さを姿勢で説明できる |
| 序破急・移動軌道・タイミング設計 | 各段の予備動作・加速・接触・余韻・接続点を示す時系列、平面軌道、支持脚と重心、現行の内部値との対応 | 段同士のテンポと一動作内の速度差を区別。移動・接触判定・命中時刻と見た目が一致し、内部値に応じた接続の変化を確認できる。見た目の都合だけで戦闘ルールを変更しない |
| Motion | キーポーズとclip／生成コード、FXなしの通常速度・低速の連続確認 | 重心移動、踏込み・振抜き・復帰が読める。足滑り、瞬間移動、定位置の手振りだけになる動き、武器貫通がない。単発と序破急の接続、被弾中断・終了後の復帰が自然 |
| VFX / SFX | 予兆・trail・接触・余韻のイベント対応表と実装、FX／音の有無で比較できる証拠 | 武器や接触点を追従し、空振りで命中演出を出さない。hitstop、音、火花等が命中イベントと同期。姿勢や相手を覆い隠さず、中断・死亡・再実行で演出が残留・重複しない |
| 実戦Simulation / Review Lab確認 | 対象技と技×敵のDeep Link、同条件の反復、通常速度の連続証拠 | 本編Simulation／registry／rendererで間合い・接触・ダメージと演出が一致。対応する体格／武器、空振り・命中・中断、序破急の連続と内部値の代表差を確認。対象外条件は明記する |
| 修正 | 原因工程への差戻しと再Review | 速度感、重量感、可読性、接続の不自然さを具体的に修正し、影響する単発／連続／実戦条件で再確認 |

FXなしでMotionの合格を確認した後、FXと音を戻して爽快感を評価する。低速再生だけではテンポを承認しない。移動軌道の見た目とSimulation上の位置を別々に捏造してダイナミックに見せない。演出増加時は同時発動での負荷と解放を確認し、性能証拠を制作記録へ残す。
