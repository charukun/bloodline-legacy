# 村の帆船と甲板

村の港の予約ボタンをなくし、桟橋から歩いて乗降する大型帆船を追加した。
出港は村で共有する世界時刻の5年ごと。15歳以上で行動できる旅人が出港時に甲板にいれば、同じ最前線へ渡る。祈り・稽古・休息中でも乗船状態は維持する。年齢条件と最前線・帰り舟の進行は従来どおりで、海上の長時間移動は追加せず既存の到着遷移を使う。

甲板には祈り場1か所、稽古人形3体、休息用の敷物を配置。活動・稽古・座る操作は既存の習得、スタミナ、疲労、負傷回復処理へ接続している。世界速度による時間の進行も同じSimulation.tick経路を使う。

船内への入口はない。甲板・傾斜した渡り板・船縁・マスト・祭壇・荷物の位置は `VILLAGE_SHIP` から管理し、歩行、ダッシュ、踏み込み、反動の共有移動判定で海への逸脱を防ぐ。足元、タップ先、台詞、活動ボタン、稽古人形は甲板の高さを使う。停泊中の帆は畳み、稽古を見渡せる形状にした。

保存とオンラインでは船の位置判定をサーバー側でも実施する。出港済み周期を保存して二重出港を防ぎ、古い記録には3体の人形だけを追加する。固定人形の追加で戦闘・成長の乱数や敵のID列は消費しない。甲板・渡り板上ではLive Updateの安全な切替を待ち、降船後に適用する。変更したルールは既存アーカイブを残して新規登録する。

## 検証

- `npm test`：ビルドと全体回帰。
- `tests/ship-deck.test.mjs`：乗降、年齢条件、船縁と障害物、3体との稽古、祈り、座っての回復、複数人の出港、遅れての乗船、保存・再接続・旧記録移行。
- `tests/ship-ui.test.mjs`：足元の祈りボタン、最寄り人形、出港表示、台詞の高さ、縦横画面での傾斜路・甲板のタップ座標。
- `tests/ship-browser.mjs` / Ship deck verification：CIのChromiumで実際のキーボード乗降、祈り・稽古ボタン、休息、保存後の出港、WebGLエラーと縦画面を確認。実際のゲームHTMLを使用する。初期位置・年齢・時間はQA fixtureで設定する。
- `tests/export_scene.mjs` と `tests/render_offline.py`：実際の描画バッチ・GLSLを使ったEGLの船全景を目視確認。

CIの画像と `report.json` は `ship-deck-<run_id>` artifact に保存される。EGLはブラウザ検証ではなく、Chromium/SwiftShaderもスマートフォン実機の性能保証ではない。developへの統合とDEV配備はIntegration WORKが担当する。
