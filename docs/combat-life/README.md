### 対峙と釣り

- 相互ターゲット、距離6以内、双方の向き±1.6rad、行動可能状態を共用する。
  画面内判定は使わない。攻撃開始時のターゲットを保持し、衝突時の向きで意識を評価する。
- 既存の盾・パリィ・回避・失明の後に、対峙時48%の追加回避。
  意識外は通常の急所打撃が32%で致命傷、その他の軽傷が55%で重傷。
  敵への意識外ダメージは1.35倍。無敵・確定即死にはしない。
- 400個の同一seedごとの初回急所打撃比較（無盾）：対峙は被弾200 / 行動不能0、
  背後は400 / 130、別ターゲットへ対峙中の2体目は400 / 130。最初の打撃で死亡0。
  既存の軽傷→重傷→致命傷の進行は別に残る。全戦闘の勝率を示す数字ではない。
- 釣りは通常の経験・閃き・習得・配分・発動経路、ID60390、序。
  既に互いに対峙している組は奪わず、味方を横から狙う敵を優先して1体。
  範囲8、効果5秒、成功後再使用12秒、息12。届かなければ通常の発動コストは消費する。
  接近は衝突を尊重し、既に始まった攻撃を途中で別方向へ振り直さない。
  対象の死亡・行動不能・退室・距離12超過・期限で解除する。
- `damageMarks` は部位ごとに回数・深さを保持。既存の傷と欠損、ボスの4つの封印を描く。
  内部HPと従来の部位破壊条件は残し、ゲージを別の数値UIへ移していない。
  継続ダメージも傷を深める。欠損した場所に傷だけが浮かないようにする。

### 行動不能、救助、死亡

- `active / downed / carried / recovering / dead` を分離。`alive`は行動不能中もtrue。
  頭・胴の致命傷とHP枯渇は行動不能へ。寿命・既存の命を使う技の死亡は維持する。
- 同じ攻撃開始時刻の連撃ではトドメ不可。行動不能から2.2秒後以降に、
  新たに開始した到達可能な通常攻撃で死亡確定。状態異常はトドメにしない。
  救助機会を時間切れ死亡で置き換えない。
- 救助距離2.2。同一room、両手足、年齢4以上、行動可、非運搬をSimulationで検証。
  自分・二重取得・遠隔実行は拒否。救助者は歩行62%、攻撃・ダッシュ・施設・舟不可。
  救助者の被弾・死亡・離脱・入力途絶8秒で降ろす。対象の死亡時にも参照を外す。
  運搬位置の正本は救助者と共有し、表示は両モデルとも腕の前に横たえる。
- 村内 z=-25.5〜22、前線拠点 x±5/z=2〜8 で12秒、それ以外は40秒で復帰。
  運搬中は回復を止め、到着時に再開。HP35・息最大30から立ち上がる。
  傷・欠損は保持し、全快・四肢再生にはしない。既存の年月による治癒は維持。
- 衛兵は進行中の一撃を終えてから、近傍14内の倒れた人物を期限付きで確保する。
  実際に歩いて拾い、柵の両側では門を経由して安全地帯へ運び、持ち場へ戻る。
  接近・持ち上げ・到着で会話。運搬中に被弾すれば降ろして戦闘に戻れる。

### 遺す技と保存

- 亡くなった本人の習得済みアクティブ技から1つ選ぶ。使用回数0の習得技も候補。
  既存の1技自動記録を置き換え、次の人生では従来どおり「閃きへの影響」を受け継ぐ。
  パッシブ、未習得技、他人の人生からの指定は候補にしない。候補0なら技なしの記録。
- 選択待ち/選択済みをschema3内に保存。死者本人用の`choose-legacy`のみ死亡後に許可。
  ホームから選択待ちを再開でき、次の新規人生は選択後に開始する。
  仲間の記録、戻る、再読込、二重クリックは選択を代行せず、記録・世代を重複させない。
  旧セーブのrecorded済み記録・archiveはそのまま保持。

### パルクール

- 既存の境界柵（高さ1.18）と中央道脇の0.30/0.60/0.90の石段に限定。
  上限は柵1.25、1動作の段差0.95。移動方向、端、通過幅、占有、着地点全体を検証する。
  建物・井戸・水際・マップ外・重傷/欠損脚・幼児抱っこ・救助運搬・行動不能は対象外。
- 柵0.68秒、段差0.55秒のSimulation状態。空中は移動/攻撃の新規入力を受けず、被弾は可能。
  中断・復元時は検証済みの開始側か着地側へ戻し、中間座標に固定しない。
  支持面と高さを同期し、描画は同じ高さを参照。カメラは既存の追従を保ち、跳躍だけでは上下させない。
