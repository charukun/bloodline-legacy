# 抱っこ・施設の手ほどき・閃きの仕上げ

2026-09-10 のユーザー依頼。開始 develop: `ac9eb52d3853aa70c126209e158ef4a8d8cabf3a`。作業中に船の PR #59 が統合されたため、`cf6fee96da1ad539ad885edbe552f2d5bbecd0e0` を作業ブランチへ取り込み、船上の祈り台・かかし・出港・高さを保持。その後の PR #60 / #61 (`713de66`) も取り込み、技の組成と設定内の更新通知を保持。PR #62 / #63 (`d561093`) の足運び・自然な日本語も保持し、技名通知は今回の金の紋章へ一本化。PR #64 (`bd984a8`) の稽古終了ボタン位置も保持し、設備前での同時表示を確認。共通運用ポリシー v5 と Implementation Prompt v2.0、BUILD_VERSION、既存の施設・スキル・世界速度仕様を確認。

- 抱っこ中も同じフリックで走る。再タッチ・別の移動入力・消耗・障害物で停止。移動速度倍率と消耗は既存のダッシュを使用し、抱っこ解除時刻、成長速度、戦闘禁止は維持。
- 母の台詞は短い一文を中心にする。施設設備の前方 4m 以内で、その設備の手ほどきを優先。発言中には割り込まず、同じ施設は 30 世界秒空ける。通常は約 3.4 秒表示し、8 世界秒ごとに発言。
- 設備の前方 0.35–2.15m、左右 1.15m 以内で施設アクションを許可。表示と実際の実行・継続・装備変更が同じ判定を使う。動作開始時は設備へ身体を向ける。ボタンの描画位置はキャラクターの足元を維持。

`facilityStation` が描画・UI・シミュレーションの正本。左右反転する村にも対応。稽古人形のボタンは既存どおり人形の上。

設定の下にヒントの紋章を追加。状態を読み取り、危険からの退避、休息、負傷、救助、未確認の学び、武具、施設の順に最大3件を提示する。死亡・救助待ち・抱っこ中は専用案内。ヒントを開いてもスキルやセーブを書き換えない。

閃きは意識ボタンの上に金の紋章・12本の光・技名を表示。通常3秒、続けて閃いた場合もひとつの表示にまとめ最大4.2秒。画面中央の覆い、入力遮断、カメラ変更、説明文や遷移ボタンは追加しない。縮小モーション設定では光を飛ばさない。既読・死亡時に消える。音はハープの上昇音と鐘の和音で、既存の音量・ミュート・距離・発音数上限を使用。

版番号の `0.6.0` は手動加算しない。DEV 公開 manifest は調査時 `v0.6.0-dev · ac9eb52` で develop と一致。一族画面の Shadow DOM への移行時に失われていた `data-build-version` と全文SHAのtitleを復元し、版の末尾を読みやすくした。設定上部と DEV/STAGING/local のプレイ画面でも同じ埋め込み情報を示す。古いHTMLが新しい版を名乗る変更はしない。PR公開だけではDEVは更新されず、Integration WORKのmergeが必要。
