# 構成式スキル Vertical Slice

## 目的と範囲

人生から閃く技の候補を、既存の40アクティブ・5パッシブに加えて、
2,304個の安定したIDを持つ構成式アクティブ技へ拡張する。
色や微小な威力差を種類数には数えない。
12打撃形 × 4拍子 × 4足運び × 4命中作用 × 3終わり方。
「2,304個の専用アニメーション／完全に異なる見た目を手作業で作った」という意味ではない。
共有モーションを実際の打撃時刻と足運びに合わせ、軌道・打点・間合い・作用・終了状態を組み合わせる。

着手基準: develop c53f9b2。技名修正の提出前に develop 10fb501 へrebase済み（広場・敵図鑑・地形・成長・UIの更新を保持）。
今回の継続作業は共通開発運用ポリシーv6（2026-09-09確認）に従う。
develop 56588fe の関係箇所を監査した後、Integrationが同じWORKへ追加した
8c2b873（船・敵の状態表現・移動描画を統合）をfast-forwardで受け取り、そこへ通常の追加コミットを載せる。
履歴の書き換え・force push・PRのmergeは行わない。既存PR #60で受け渡す。

## 部品と接続

| 軸 | 内容 |
| --- | --- |
| 打ち方 | 針拳、炉拳、毬蹴、追枝、割拍、静掌、響打、羽輪、礎落、炭払、綾刃、結脚 |
| 拍子 | 一閃、等間隔の双返、時間差の間返、三綴 |
| 足運び | 据える、前進、横へ回る、引き足 |
| 命中作用 | 怯み、減速、弱体、押し離し |
| 終わり方 | 詰める、構えを整える、引く |

序破急の所属は構成から決まり、各ページ768個の候補を持つ。
前技が残す「近さ／拍子」と、次技が求める「近さ／拍子／崩れ」を
既存の接続判定に渡す。単に3技を置くだけで必ずボーナスが発生するわけではない。
崩れは既存技が残す状態にも接続できる。

`beatCuts` をSimulationの接触スケジュールとSkillMotionの拍子時計で共有。
既存キャラクターのクリップ再生もこの時計を使う。
前進・横移動・後退は既存の衝突処理を通す。負傷、拘束、年齢補正を適用。
回避・ガードされた正の威力の打撃は、状態作用・押し出し・接続を発生させない。
古い技の踏み込みタイミングと定義は維持する。

## 人生・習得・保存

- 既存の技族へ候補を加える。族の抽選重みを構成数で膨らませない。
- 候補の根拠が単一経験だけの族には、異なる種類の経験との交差を要求する。
- 小物は経験の由来として働く。血統は技族・経験への偏りとして働き、技はコピーしない。
- 習得済み技、所持品、武器、負傷、人生seed等の既存条件を利用する。
- アクティブの遅い習得ペースとパッシブの既存機会を保持。上限まで一生で覚える仕様ではない。
- 永続コードからIDとkeyを決定する。表示順や色seedでIDを変えない。
- 保存は既存schema4のID・編成・経験・閃き履歴を使い、復元で再抽選しない。
- 毎フレーム全候補を走査しない。経験イベントから索引で族を絞り、同じ条件の由来判定を機会内で共有する。
- ブラウザーとサーバーに同じ小さな構成定義を埋め込む。2,304定義の重複JSONは出荷しない。
- 既存の不変サーバールールは保持し、構成技導入・技名修正・後続developとの統合に対応するルールを追加する。

## 確認用HTML

### 技名と表示

- 技名は `names.ja` / `names.en` の対。英名は内部の部品keyの羅列にしない。
- 構成技は48組の「打ち方・拍子を思わせる名称」と48組の情景語を用意し、
  自然な和名・英名を組み立てる。例: **夕凪の待ち針 / Evening Calm Patient Needle**。
  2,304件それぞれを両言語で区別できる。情景語は技の呼び名であり、実際の習得経験を捏造するものではない。
- 一文字の部品コードや `〈崩繋〉` 等は技名へ入れない。序破急は別の編成表示。
- 意識UIは和名を一覧に、和名＋英名を詳細に表示。稽古帳も両名と編成する段を分けて表示。
- 呼び名は構成IDごとに固定し、人生・使用・ロードで変化させない。
  既存45件の名称、全技のID・key・挙動・習得条件・保存形式は変更しない。
- 名前データも不変サーバールールに含まれるため、新しいアーカイブを追加する。
  以前配布した名前を含む旧アーカイブは保持する。

`npm run build:skill-composition-lab`

出力: `dist/Bloodline_Legacy_Skill_Composition.html`

5軸の組み替え、6見本、一技／序破急、かかし・敵・複数相手、開始距離、
再生速度、カメラ、同条件リプレイ、構成JSON保存／読込。
本物のSimulationとSliceRendererを使う。稽古用に選んだ技を明示的に開放し、
本編のセーブやネットワークには接続しない。

### 移動・武器・ランダム試用の更新

- 構成技の前進を0.85→1.9、横移動を0.6→1.25、引き足を0.45→0.9へ調整。
  終わりの追い足は0.35→0.8、離脱は0.65→1.35。単位はゲーム内距離。
  横移動中は相手へ滑らかに向き直り、壁・相手との間隔・拘束・負傷の既存制約を通す。
  名前・ID・習得頻度・威力・消費スタミナはこの調整で変えない。
- 稽古帳の初期カメラを固定。追従は任意で切替えられ、足運びを見比べやすくする。
  開始距離の手動指定に加えて、選んだ技の間合いに合わせる操作を追加。
- ランダムな一技の生成、直前の構成への復帰、序破急の一括抽選を追加。
  抽選は稽古帳専用seedを使い、本編の抽選や同条件試験のSimulation seedに干渉しない。
- 構成式2,304技は素手系。武器別2,304技を追加したという意味ではない。
  6武器の既存9技も試せるようにし、武器に合わない既存技の編成を防ぐ。
  構成技と武器技は混在編成でき、素手技の間は所持武器を背に預ける表示になる。
  装備状態や能力値は変更しない。専用の納刀アニメーションは未実装。
- 素手技が装備武器の剣クリップ・両手持ち補正・武器先端トレイルを借りないようにする。
  武器技は既存モデルと手の接続を使い、9技のエフェクトを武器先端と命中に結び付ける。
  専用モーションを全武器・全構成に制作したという意味ではない。
- 技に対応する演出の系統・軌道・命中・消え方を表示。演出ON/OFFで同じ戦闘を再生できる。
  個々の火花の見た目は描画側に閉じ、演出切替えで命中・移動結果を変えない。
- 稽古帳JSONをversion2へ拡張し、武器・抽選seedも保存。従来のversion1も読み込める。
  本編save schema4とは別。新しい複合サーバールールを追加し、公開済みアーカイブを保持。
