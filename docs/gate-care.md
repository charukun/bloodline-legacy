- 4歳の攻撃力・対峙中回避は成人の18%から連続的に成長し15歳で成人値になる。7歳未満はエリートの直撃で倒れ、素手の打ち合いや構えだけでは受け止められない。既存の加護は有効。幼児の弱い攻撃ではエリートの部位を落としたり予備動作を潰せない。成人の既存挙動と稽古・習得は維持する。
- 32%未満でオーブが琥珀色、16%未満で赤銅色に明滅。蓄積疲労で最大値が40%未満でも知らせる。回復の境界には幅を持たせ、短い息切れ・呼吸音を実時間で間引く。画面を覆わず、発言やゲーム入力・世界時計を変更しない。座る、倒れる、死亡、幼児導入中は息切れ表現を止める。動きを減らす設定にも対応。
- 村の門内側(x=8,z=-23)に開放型の治療所と救護班2名を配置。中央通路を塞がない。足元ボタンで既存の座る処理を開始し、治療所の範囲内で生命力・負傷回復を早める。失った部位は再生しない。
